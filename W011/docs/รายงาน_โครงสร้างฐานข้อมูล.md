รายงานโครงงาน
ระบบ Dashboard วิเคราะห์ข้อมูลการขายด้วย Laravel และ Chart.js

1. บทนำ
โครงงานนี้จัดทำขึ้นเพื่อออกแบบฐานข้อมูลสำหรับเก็บข้อมูลการขาย และพัฒนาเว็บแอปพลิเคชันด้วย Laravel ที่นำข้อมูลจาก MySQL มาแสดงผลเป็น Dashboard และกราฟด้วย Chart.js

2. วัตถุประสงค์
1) ออกแบบฐานข้อมูลเชิงสัมพันธ์
2) เพิ่มข้อมูลการขายไม่น้อยกว่า 100 เรคอร์ด
3) พัฒนาเว็บด้วย Laravel
4) แสดงข้อมูลในรูปแบบกราฟเพื่อช่วยให้ดูแนวโน้มและเปรียบเทียบข้อมูลได้ง่าย

3. โครงสร้างฐานข้อมูล
ฐานข้อมูล: sales_dashboard

ตาราง categories
- id: BIGINT, Primary Key
- name: VARCHAR(100), ชื่อหมวดหมู่
- created_at, updated_at: TIMESTAMP

ตาราง products
- id: BIGINT, Primary Key
- category_id: BIGINT, Foreign Key -> categories.id
- name: VARCHAR(150), ชื่อสินค้า
- price: DECIMAL(10,2), ราคาต่อหน่วย
- created_at, updated_at: TIMESTAMP

ตาราง sales
- id: BIGINT, Primary Key
- product_id: BIGINT, Foreign Key -> products.id
- sale_date: DATE, วันที่ขาย
- quantity: INT, จำนวนสินค้า
- unit_price: DECIMAL(10,2), ราคาต่อหน่วย ณ วันที่ขาย
- total_amount: DECIMAL(12,2), ยอดรวม
- created_at, updated_at: TIMESTAMP

4. ความสัมพันธ์
categories 1:N products
products 1:N sales

5. ข้อมูล
มีข้อมูลการขาย 120 เรคอร์ด มากกว่าเกณฑ์ขั้นต่ำ 100 เรคอร์ด
- categories: 5 records
- products: 30 records
- sales: 120 records
รายการข้อมูลทั้งหมดอยู่ใน docs/sales_120_records.csv

6. การทำงานของ Dashboard
- ยอดขายรวม: SUM(total_amount)
- จำนวนรายการขาย: COUNT(sales)
- จำนวนสินค้าที่ขาย: SUM(quantity)
- กราฟเส้น: ยอดขายรายเดือน
- กราฟวงกลม: ยอดขายตามหมวดหมู่
- กราฟแท่ง: สินค้าขายดี 10 อันดับ
- ตาราง: รายการขายล่าสุด

7. เทคโนโลยี
Laravel, PHP, MySQL, Blade, Chart.js, HTML, CSS, JavaScript

8. ขั้นตอนการติดตั้ง
1) สร้าง Laravel project
2) นำไฟล์จากชุดงานนี้ไปวางตามโครงสร้าง
3) สร้าง database ชื่อ sales_dashboard
4) ตั้งค่า .env
5) php artisan key:generate
6) php artisan migrate:fresh --seed
7) php artisan serve
8) เปิด http://127.0.0.1:8000

9. ผลลัพธ์
หน้า Dashboard แสดงตัวเลขสรุปและกราฟ 3 รูปแบบ พร้อมตารางรายการขายล่าสุด
ภาพตัวอย่างอยู่ใน docs/dashboard_example.png

10. สรุป
โครงงานสามารถจัดเก็บข้อมูลแบบสัมพันธ์ เพิ่มข้อมูลจำนวนมากด้วย Seeder และนำข้อมูลมาวิเคราะห์ผ่าน Dashboard ได้ โดยใช้ Laravel เป็น Backend และ Chart.js เป็นส่วนแสดงผลกราฟ
